# Defect Report — DEF-003

## Title
Task title leading and trailing whitespace not stripped before storage

## Severity
Medium

## Priority
P3

## Status
Closed

## Reported By
Santhosh Malarvannan — QA Engineer

## Date Reported
2025-09-10

## Environment
- Application: ToDoApp Task Management API
- Component: Task Management — POST /tasks endpoint
- Python: 3.9.6
- Flask: 3.1.3
- OS: macOS

## Summary
When creating a task with a title containing leading or trailing whitespace
such as "  Buy groceries  ", the whitespace was being stored as part of
the title rather than being stripped. This caused inconsistent display
in the UI and made string comparisons unreliable.

## Steps to Reproduce
1. Register a user
2. POST /tasks with title "  Buy groceries  "
3. GET the created task
4. Observe the stored title value

## Expected Result
Title stored as "Buy groceries" with whitespace stripped

## Actual Result
Title stored as "  Buy groceries  " with whitespace preserved

## Root Cause
The create task endpoint was not calling .strip() on the title field
before storing it, unlike the name field in the authentication module
which did strip whitespace correctly.

## Impact
Medium — inconsistent data storage causes UI display issues and makes
search and comparison operations unreliable. Tasks with whitespace in
titles would not match correctly in filter operations.

## Suggested Fix
Call .strip() on the title field in the create task endpoint before
storing the task, consistent with how the name field is handled in
the register endpoint.

## Verification
Fix applied. Test test_create_task_title_whitespace_stripped now passes.
All 94 regression tests passing after fix.
